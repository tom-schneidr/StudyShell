StudyShell

A local-first desktop workspace for course material as files.

StudyShell brings notes, code, PDFs, notebooks, media previews, search, flashcards, quizzes, and optional FreeRouter-backed AI assistance into one Tauri desktop app.

What Works Today

  • Workspace file browser with live refresh and native filesystem access.
  • Markdown, plain text, and CodeMirror-backed code editing.
  • PDF viewing, annotation sidecars, image/media previews, and notebook rendering.
  • AI chat, summarization, flashcards, and quizzes through local FreeRouter.
  • Recent files, pinned files, command palette, search, split view, and study timer.

Quick Start

npm ci
npm run tauri:dev

AI features expect FreeRouter at http://127.0.0.1:8000/v1. Configure provider keys in FreeRouter, not inside StudyShell.

Verification

npm run verify:frontend
npm run verify:rust
npm run build
npm audit --omit=dev --audit-level=high

npm run tauri:build creates a platform-specific installer locally. It is not run in the Linux CI job.
